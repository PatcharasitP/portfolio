## แนวคิดการออกแบบ

ทุกการตัดสินใจอ้างอิงงานวิจัยที่เก็บไว้ใน `.claude/research/2026-09-07-portfolio-ux-design.md`:

| หลักการ | สิ่งที่ทำ |
|---|---|
| recruiter สแกนหน้าแรกราว 6–7 วินาที | ชื่อ ตำแหน่ง และปุ่มหลักอยู่ครึ่งหน้าบนทั้งหมด · ทุกโปรเจกต์มี "ผลลัพธ์" เป็นบรรทัดเด่นที่อ่านได้โดยไม่ต้องกด |
| 3–5 โปรเจกต์ที่แข็งชนะโปรเจกต์เยอะ ๆ | เลือกมา 4 ชิ้นที่เล่าได้ครบตั้งแต่โจทย์ถึงผลลัพธ์ |
| case study ต้องปิดด้วยตัวเลข | ใช้โครง Context → Action → Result → Learning ทุกชิ้น พับเก็บไว้ให้คนที่สนใจกดอ่าน |
| WCAG 2.1 AA | ทุกคู่สีวัดจริงแล้วผ่าน 4.5:1 (ต่ำสุด 5.18:1) ทั้งโหมดสว่างและมืด |
| โหมดมืดที่ไม่ทำร้ายตา | พื้น `#141414` ตัวอักษร `#e6e6e1` — ไม่ใช้ดำสนิทหรือขาวสนิท และให้ผู้ใช้เลือกเองได้ |
| เคารพการตั้งค่าผู้ใช้ | แอนิเมชันปิดอัตโนมัติเมื่อผู้ใช้ตั้ง `prefers-reduced-motion` |

## ผลการวัด

- First Contentful Paint **56 ms** · 3 ไฟล์ · ไม่มีไลบรารีภายนอก
- ความสูงหน้า 4,356 px (ก่อนปรับให้พับเคสได้คือ 10,428 px)
- ทดสอบอัตโนมัติ 12 ข้อผ่านทั้งหมด (contrast, สลับภาษา, จำโหมดสี, พับ/กางเคส)

## โครงสร้าง

```
Portfolio/
├── index.html          โครงหน้า + โทเคนดีไซน์ + CSS ทั้งหมด (inline ไม่ต้องรอไฟล์นอก)
├── src/
│   ├── content.js      เนื้อหาทั้งเว็บ สองภาษาในไฟล์เดียว — แก้ที่นี่ที่เดียว
│   └── app.js          วาดหน้าจากเนื้อหา + สลับภาษา/โหมดสี
└── assets/             รูปโปรไฟล์ · ภาพพรีวิวตอนแชร์ · ไฟล์ CV
```

## แก้เนื้อหา

เปิด `src/content.js` แล้วแก้ได้เลย — ทุกข้อความมีคู่ `th` / `en` อยู่ติดกัน
เพิ่มโปรเจกต์ใหม่ = เพิ่ม object ใน `projects` โดยใส่ `impact` (ผลลัพธ์ 1 บรรทัด) และ `carl` (4 หัวข้อ) ให้ครบทั้งสองภาษา

cd Portfolio && python3 -m http.server 8790
